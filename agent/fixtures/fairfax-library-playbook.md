# Fairfax County Public Library Guidance

## Service updates

Share FCPL branch hours, closures, and service notices only after verifying them on the
official Fairfax County Public Library pages.

## Required documents

Library card and account rules must come from official county library pages.

## Language assistance

Offer language assistance contacts published by Fairfax County Public Library.

## Application support

Help patrons find branch and catalog information. Never enter library account credentials
into Civic Canary.
