# Community Library Patron Guidance

## Service updates

Share branch open/closed status and holds pickup locations only after verifying them on the
official library portal. If a branch is closed or relocated, direct patrons to the temporary
pickup site listed by the library.

## Required documents

Library card requirements come from the official portal. Do not invent substitute ID rules.

## Language assistance

Offer language assistance contacts published by the library system.

## Application support

Help patrons find holds and event information. Never enter account credentials for a patron.
